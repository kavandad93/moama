# MOAMA — پرونده‌های حل‌نشده

یک تجربه‌ی داستانی تعاملی فارسی با ظاهر بایگانی محرمانه و پرونده‌های قابل بررسی.

## اجرا

`index.html` را روی هر وب‌سرور استاتیک قرار دهید یا مستقیماً در مرورگر باز کنید.

## ساختار

- `index.html` — بایگانی، پوشه پرونده و رابط تحقیق
- `assets/css/style.css` — طراحی سینمایی، پوشه‌ها، اسناد و واکنش‌گرایی
- `assets/js/app.js` — ناوبری و بررسی نظریه
- `assets/images/missing-person.svg` — تصویر SVG پرونده
- `assets/images/evidence-room.svg` — تصویر SVG صحنه پرونده

## پرونده 001

فعلاً فقط یک پرونده در بایگانی فعال است. بازیکن باید اسناد، تصاویر، خط زمانی، اظهارات، پیام‌ها و افراد مرتبط را کنار هم بگذارد و در پایان نظریه‌ی خود را با نام فرد و دلیل ارائه کند.

پاسخ پرونده عمداً در README یا متن معرفی پروژه قرار داده نشده است.

> تمام محتوای پرونده داستانی است.
