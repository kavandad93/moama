# MOAMA — پرونده‌های حل‌نشده

یک بازی داستانی تعاملی فارسی با ساختار پرونده‌های محرمانه.

## اجرا

فایل `index.html` را روی هر وب‌سرور استاتیک قرار دهید یا مستقیماً در مرورگر باز کنید.

## ساختار

- `index.html` — رابط و محتوای پرونده
- `assets/css/style.css` — طراحی و واکنش‌گرایی
- `assets/js/app.js` — ناوبری، پاسخ معما و Easter Egg

## پرونده 001

بازیکن با بررسی شش مدرک باید رمز چهاررقمی پرونده را پیدا کند. پاسخ فعلی: `2317`.

تمام محتوای پرونده داستانی است.
